# SOP Generator — AI Prompt Pack

Use these prompts with ChatGPT, Claude, or any AI assistant to generate complete SOPs from rough notes, verbal descriptions, or bullet points.

---

## Prompt 1: Generate a Full SOP from a Process Description

Copy and paste this prompt, replacing the bracketed sections:

```
You are an operations consultant who writes clear, actionable SOPs for small businesses.

I'm going to describe a process that my business does. I want you to turn it into a complete, professional SOP document with the following sections:

1. Purpose (why this process exists)
2. Scope (who it applies to, when it triggers, what's out of scope)
3. Roles & Responsibilities (table format)
4. Prerequisites (what needs to be true before starting)
5. Procedure (numbered steps with sub-steps, checkboxes, and specific details)
6. Decision Points (if/then table for branching scenarios)
7. Tools & Resources (table with tool name, purpose, and access link)
8. Quality Checkpoints (how to verify it was done correctly)
9. Exceptions & Escalation (common problems and who to contact)
10. Revision History (empty table for tracking changes)

Write it so that someone doing this for the first time could follow it without asking any questions. Use checkboxes for action items. Be specific — don't say "send an email," say what the email should contain.

Here's the process:

[PASTE YOUR ROUGH DESCRIPTION HERE — bullet points, voice notes transcript, or just describe it however you can]
```

## Prompt 2: Generate an SOP from a Job Description

```
I want to create SOPs for a role in my business. Below is the job description. For each major responsibility listed, generate a separate SOP that documents exactly how to perform that responsibility.

For each SOP, include:
- Purpose
- Step-by-step procedure with checkboxes
- Tools needed
- Quality checkpoints
- Common mistakes to avoid

Keep each SOP to one page if possible. Write for someone who is new to the role.

Job Description:

[PASTE THE JOB DESCRIPTION HERE]
```

## Prompt 3: Turn Meeting Notes into an SOP

```
Below are rough notes from a meeting where we discussed a process. Convert these notes into a clean, structured SOP.

Fill in any logical gaps — if a step is implied but not stated, include it. After the SOP, list any questions or assumptions you had to make so I can verify them.

Meeting Notes:

[PASTE YOUR MEETING NOTES HERE]
```

## Prompt 4: Generate an SOP from "How I Do It" Brain Dump

```
I'm going to describe something I do in my business the way I'd explain it to a friend. It's going to be messy and informal — that's fine. Your job is to turn my brain dump into a professional, structured SOP.

Rules:
- Keep my voice and intent, but make it clear and organized
- Add steps I probably forgot (things that are obvious to me but wouldn't be to someone new)
- Flag anything that sounds like a bottleneck or single point of failure
- Include checkboxes for every action item
- Add a "Common Mistakes" section based on what could go wrong

My brain dump:

[JUST START TYPING OR PASTE A VOICE TRANSCRIPT — DON'T WORRY ABOUT FORMATTING]
```

## Prompt 5: Batch-Generate SOPs for a Department

```
I need to document all the key processes for the [DEPARTMENT NAME] function of my small business.

First, suggest a list of 8-10 SOPs that a [DEPARTMENT NAME] department/function should have. For each one, write a one-sentence description of what it would cover.

Then I'll tell you which ones to write first.

Context about my business:
- Industry: [YOUR INDUSTRY]
- Company size: [NUMBER OF EMPLOYEES]
- Tools we use: [LIST YOUR MAIN TOOLS]
- Biggest pain point: [WHAT KEEPS BREAKING OR CAUSING PROBLEMS]
```

```

The training companion should include:
- A 5-minute overview script (what to say when walking someone through this)
- 3 quiz questions to verify understanding
- A "cheat sheet" version (one-page summary they can print and keep at their desk)

Process to document:

[DESCRIBE THE PROCESS]
```

## Prompt 7: Convert an Existing Checklist into a Full SOP

```
I have a checklist that my team uses, but it's missing context — people follow the steps but don't understand why, and when something goes wrong they don't know what to do.

Take this checklist and expand it into a complete SOP. For each checklist item:
- Explain WHY this step matters
- Add detail on HOW to do it (not just what to do)
- Note what could go wrong and how to handle it

Current Checklist:

[PASTE YOUR EXISTING CHECKLIST]
```

## Tips for Best Results

1. **More input = better output.** A paragraph gets you a generic SOP. A detailed brain dump gets you one that actually matches your business.
2. **Include your tools.** Mention the specific software, platforms, and tools you use — the AI will write steps specific to those tools.
3. **Specify your audience.** Add "Write this for someone with no experience in [field]" or "The reader is a senior [role] who just needs the process, not the basics."
4. **Iterate.** Generate the first version, then ask: "Make step 3 more detailed" or "Add a section about what to do when [edge case] happens."
5. **Validate with your team.** Have someone who does this process actually read the SOP and tell you where it's wrong or unclear.
