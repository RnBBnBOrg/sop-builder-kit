# Welcome to the SOP Builder Kit

You're 30 minutes away from your first documented process.

**Start here:** Open [`guides/quick-start.md`](guides/quick-start.md) for step-by-step instructions.

## What's in the box

| Folder | What's inside |
|--------|---------------|
| `templates/` | 5 ready-to-use SOP templates (Notion-compatible markdown) |
| `prompts/` | 3 AI prompt packs — 22 prompts for generating, auditing, and customizing SOPs |
| `guides/` | Quick-start guide with priority framework and Notion import instructions |

## Fastest path to your first SOP

1. Open `guides/quick-start.md`
2. Pick your most painful process using the priority framework
3. Copy Prompt 1 from `prompts/sop-generator.md` into ChatGPT, Claude, or any AI tool
4. Paste in your rough notes and run it
5. Import the result into Notion

Questions? Open an issue at https://github.com/RnBBnBOrg/sop-builder-kit
