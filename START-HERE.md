# Welcome to the SOP Builder Kit

You're 30 minutes away from your first documented process.

**Start here:** Open [`guides/quick-start.html`](guides/quick-start.html) for step-by-step instructions.

## What's in the box

| Folder | What's inside |
|--------|---------------|
| `templates/` | 5 interactive SOP templates — fill in directly in your browser |
| `prompts/` | 3 AI prompt packs — 22 prompts for generating, auditing, and customizing SOPs |
| `guides/` | Quick-start guide with priority framework and setup instructions |

## Fastest path to your first SOP

1. Open `guides/quick-start.html`
2. Pick your most painful process using the priority framework
3. Copy Prompt 1 from `prompts/sop-generator.html` into ChatGPT, Claude, or any AI tool
4. Paste in your rough notes and run it
5. Fill in the template with the result

Questions? Open an issue at https://github.com/RnBBnBOrg/sop-builder-kit
