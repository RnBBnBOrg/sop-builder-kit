## 1. Purpose

Take content from raw idea to published and promoted — with consistent quality, clear approvals, and nothing sitting in draft purgatory forever.

---

## 2. Scope

- **Applies to:** All published content (blog posts, social media, newsletters, case studies, videos)
- **Triggers:** Approved content idea added to the content calendar
- **Does NOT cover:** Paid advertising copy, legal/compliance documents, or internal-only communications

---

## 3. Roles & Responsibilities

| Role | Responsibility |
|------|---------------|
| Content Lead / Manager | Owns the calendar, assigns work, final approval |
| Writer / Creator | Produces the draft, incorporates feedback |
| Editor / Reviewer | Reviews for quality, accuracy, brand voice |
| Designer (if applicable) | Creates visuals, graphics, thumbnails |
| Publisher | Formats, schedules, and publishes the final piece |

*In a small team, one person may fill multiple roles.*

---

## 4. Content Pipeline Stages

| Stage | Status | Owner |
|-------|--------|-------|
| 1. Idea | Proposed | Anyone |
| 2. Approved | On the calendar | Content Lead |
| 3. Drafting | In progress | Writer |
| 4. Review | Feedback needed | Editor |
| 5. Revisions | Incorporating feedback | Writer |
| 6. Final Approval | Ready to publish | Content Lead |
| 7. Scheduled | Queued for publish date | Publisher |
| 8. Published | Live | Publisher |
| 9. Promoted | Distributed across channels | Content Lead |

## 5. Procedure

### Stage 1: Idea Capture

**Who:** Anyone on the team

- [ ] Add idea to the content backlog with:
  - Working title
  - Target audience
  - Key message or angle
  - Content type (blog, social, newsletter, video, etc.)
  - Source of idea (customer question, trend, internal expertise, keyword research)

**Idea Evaluation Criteria:**
| Criteria | Question |
|----------|----------|
| Relevance | Does our audience care about this? |
| Expertise | Can we say something credible and useful? |
| Timeliness | Is this relevant now or evergreen? |
| Business Alignment | Does this support our goals (leads, authority, SEO)? |

---

### Stage 2: Approval & Assignment

**Who:** Content Lead

- [ ] Review ideas weekly (or at planning cadence)
- [ ] Approve, reject, or defer each idea
- [ ] For approved ideas:
  - Assign a writer
  - Set a target publish date
  - Add to the content calendar
  - Provide a brief:

**Content Brief Template:**

| Field | Details |
|-------|---------|
| **Title / Topic** | [Working title] |
| **Content Type** | Blog / Social / Newsletter / Video / Case Study |
| **Target Audience** | [Who is this for?] |
| **Goal** | [What should the reader do/feel/know after?] |
| **Key Points to Cover** | [Bullet list of must-include topics] |
| **Target Length** | [Word count or duration] |
| **SEO Keywords** | [Primary and secondary keywords, if applicable] |
| **References / Research** | [Links, data sources, examples] |
| **Tone** | [Professional / Conversational / Technical / etc.] |
| **Deadline — First Draft** | [Date] |
| **Target Publish Date** | [Date] |

---

### Stage 3: Drafting

**Who:** Writer / Creator

- [ ] Write the first draft based on the brief
- [ ] Include:
  - Headline (aim for 3 options)
  - Introduction that hooks the reader in the first 2 sentences
  - Body content organized with subheadings
  - Conclusion with a clear call-to-action
  - Meta description (for SEO content)
- [ ] Add notes for designer (image needs, graphics, screenshots)
- [ ] Move status to "Review" when draft is ready

**Writing Checklist:**
- [ ] Does the opening hook the reader?
- [ ] Is every section earning its place? (Cut ruthlessly)
- [ ] Are claims backed by data, examples, or experience?
- [ ] Is there a clear call-to-action?
- [ ] Would I share this if I saw it in my feed?

---

### Stage 4: Review

**Who:** Editor / Reviewer

- [ ] Review within **2 business days** of receiving the draft
- [ ] Check for:
  - [ ] Accuracy — are facts, stats, and claims correct?
  - [ ] Clarity — can the target audience understand this without re-reading?
  - [ ] Brand voice — does this sound like us?
  - [ ] Structure — does it flow logically?
  - [ ] Grammar and spelling
  - [ ] SEO — keywords used naturally, meta description present
- [ ] Leave specific, actionable feedback (not just "make it better")
- [ ] Move status to "Revisions"

---

### Stage 5: Revisions

**Who:** Writer

- [ ] Address all feedback
- [ ] If you disagree with a suggestion, explain why (don't silently ignore it)
- [ ] Move status back to "Review" if major changes, or to "Final Approval" if minor

---

### Stage 6: Final Approval

**Who:** Content Lead

- [ ] Final read-through
- [ ] Confirm it matches the brief
- [ ] Approve or request one more round
- [ ] Once approved, move to "Scheduled"

---

### Stage 7: Formatting & Scheduling

**Who:** Publisher

- [ ] Format for the target platform:
  - [ ] Add images, graphics, or media
  - [ ] Format headings, lists, links
  - [ ] Add internal/external links
  - [ ] Set featured image and alt text
  - [ ] Add meta title and description
  - [ ] Add categories/tags
- [ ] Preview the published version (check formatting on desktop AND mobile)
- [ ] Schedule for the target publish date and time

---

### Stage 8: Publish & Promote

**Who:** Publisher + Content Lead

**On publish:**
- [ ] Verify the post is live and formatted correctly
- [ ] Check all links work

**Promotion checklist (within 24-48 hours):**
- [ ] Share on social media (LinkedIn, X/Twitter, Facebook, Instagram — whichever applies)
- [ ] Send to email list / newsletter (if applicable)
- [ ] Share internally with the team (Slack / email)
- [ ] Notify anyone mentioned or quoted in the piece
- [ ] Submit to relevant communities or forums (if appropriate)
- [ ] Repurpose: pull 3-5 social snippets, a quote graphic, or a short video clip
