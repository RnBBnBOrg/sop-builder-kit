Tips for Using This Template

  1. Fill in the purpose first — if you can't explain why this SOP exists in one sentence, the process isn't clear enough yet
  2. Write for your replacement — assume the person reading this is doing it for the first time
  3. Use screenshots — a picture of where to click beats a paragraph of description
  4. Test it — have someone unfamiliar with the process follow the SOP and note where they get stuck
  5. Review quarterly — set a calendar reminder to check if the SOP still matches reality
